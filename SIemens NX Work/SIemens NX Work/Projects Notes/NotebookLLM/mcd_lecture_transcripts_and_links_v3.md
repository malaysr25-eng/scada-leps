## 3. Recommended Workflow for Obtaining Transcripts
If you require written text transcripts for Claude Code or offline reading:
1. Open each SharePoint Stream link in your web browser.
2. Click the **View Transcript** button in the SharePoint Stream player.
3. Export or copy the transcript text directly into a markdown or `.txt` file.
4. Upload the generated transcript files into your Gemini Notebook or Claude Code workspace.
